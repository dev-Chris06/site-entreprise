# Bénin Tech Labs — site vitrine

> **Projet fictif.** Bénin Tech Labs n'existe pas : le nom de l'entreprise, ses
> contenus et ses coordonnées ont été créés pour ce projet de démonstration.

Site vitrine de sept pages pour une entreprise de conseil IT et de
développement logiciel.

**Démo en ligne :** https://dev-chris06.github.io/site-entreprise/

## Pages

Accueil, À propos, Services, Projets, Carrières, Blog et Contact.

## Fonctionnalités

- Navigation adaptée au mobile et lien d'accès direct au contenu.
- Thème clair ou sombre, mémorisé dans le navigateur.
- Sections de services et de projets avec appels à l'action.
- Métadonnées Open Graph, `sitemap.xml` et `robots.txt`.

## Technologies

HTML, CSS et JavaScript, sans framework ni étape de build. Le site fonctionne
en ouvrant `index.html` directement.
